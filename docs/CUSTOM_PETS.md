# v1.1.1 自訂寵物

## 操作與相容性

1. 右鍵 →「匯入自訂寵物 PNG／GIF…」，選檔並命名。
2. 自訂角色使用三個獨立角色槽，各組有名稱、七動作、使用／匯入／編輯／清除選單；只快取目前使用中的一組，原本貓狗十種外觀都保留。切換、改名、匯入動作不會呼叫計時器的開始／停止。
3. 「匯入自訂動作素材」可補待機、眨眼、睡覺、撒嬌、生氣、愛心、提醒。重匯待機代表替換整個自訂角色，會清掉原自訂動作對應；其他動作只覆換該槽。
4. 靜態 PNG 或缺少動作時，以呼吸、縮放、搖動、伸展、睡眠標記／愛心／生氣符號補足；拖曳拉伸、回彈、提醒跳躍沿用原本機制。沒有眨眼原畫時只做短暫壓縮，不能從任意原畫推斷眼睛位置；如需真正閉眼，匯入獨立眨眼 PNG／GIF。
5. 改名仍使用原有「修改名稱」。自訂與原生寵物的名稱分開保存。

## 離線儲存、繪製與限制

- 程式沒有素材下載器或網路播放功能；只有既有 GitHub 更新可連網。
- 原檔按 SHA-256 命名，複製至 `%LOCALAPPDATA%\DesktopPet\custom-pets`。設定只接受 64 個小寫十六進位字元加 `.png`／`.gif`，不接受 URL、任意路徑或路徑穿越。
- 設定新增 `customProfiles` 三組及 `activeCustom`；v1.1.0 的 `customFiles`／`customName` 自動遷移第一組，並保留第一組的舊欄位別名，schema 1 維持相容。`pet=2` 指自訂，`pet=3` 為鸚鵡、`pet=4` 為熊貓。資料遺失／檔案損毀時以待機動作補足，待機也無法載入時回到橘貓，計時狀態仍按原啟動規則處理。
- 用 Windows GDI+ 解碼 PNG／GIF，再快取預乘 alpha 像素；所有影格取透明邊界聯集，先裁切再縮放，避免 GIF 各幀跳動、透明邊緣黑暈以及大留白導致畫質流失。只裁透明邊，不猜測白背景。原檔不被覆寫。
- 自訂圖採平滑縮放，原有像素貓狗繼續最近鄰縮放；沒有改製或重新生成既有素材。
- 每檔上限 8 MiB，邏輯畫布不超過 2048×2048，GIF 最多 120 幀。解碼前檢查邏輯畫布×影格×4 不超過 16 MiB；過大的檔案請先縮小或減幀。
- 每個動作裁切後最多約 2 MiB／最長邊 256 像素，七槽最多約 14 MiB 像素快取（不含 OS／解碼器瞬間記憶體）。這是程式上限，不是已實測的 Working Set 數據。
- GIF 依延遲時間離線循環，最短幀延遲 40 ms、最長 10 秒；畫面更新沿用約 12 FPS，睡覺約 4 FPS、拖曳約 60 FPS。過密 GIF 可能跳幀，但時間軸不以繪圖次數累加。一般互動有獨立動畫時延長到最多 10 秒，提醒仍保留到確認。
- PNG 只讀取單張圖，不提供 APNG 動畫。GIF 解碼遵循 Windows GDI+，已加入透明／局部影格與 disposal 測試，仍須在 Windows CI 實際執行確認。
- 素材存在系統使用者資料夾；可攜 EXE 換電腦時需另行搬移自用素材。匯入後即使原來源檔被移動仍可離線使用。取消、失敗匯入可能留下未被設定引用的雜湊檔，可在關閉程式後手動清理不再使用的素材。

## 小桃（モモンガ／Momonga）本地測試來源

2026-11-25 找到並下載下列公開預覽，用於本次工作區的本地素材測試：

- 官方商品頁：[ちいかわ(モモンガ多) — LINE STORE](https://store.line.me/stickershop/product/32411274/ja)
- 原作者：ナガノ；商品頁標示 `©nagano`。
- [官方透明預覽 PNG](https://stickershop.line-scdn.net/stickershop/v1/product/32411274/LINEStorePC/main.png?v=1)，240×240，帶原畫及文字。
- **未找到授予桌面寵物改作或再散布的授權。** 沒有將可查看／可下載或購買貼圖視為取得 GitHub、軟體或素材包再散布權；本地測試也不宣稱自動取得授權。
- 素材及來源紀錄置於專案目錄之外的 `local-only/momonga`，不包含在這次程式碼修正包、GitHub 或 Release。程式碼也不自動下載該檔。

本地測試以實際 PNG 解析尺寸及 RGBA 像素，使用 C++ 共用裁切／取樣核心驗證：透明邊界 `(6,32)-(234,209)`，裁後 228×177、161424 bytes 像素快取。PNG 解析／像素讀取由 Pillow 做測試輸入，實際正式程式僅用原生 GDI+，不需 Python Runtime。

如需自行測試，請在確認自己的使用權限後取得檔案，從程式匯入並命名「小桃」。不要求取得再散布授權前將圖片上傳到 issue、Git、Release 或測試報告。缺少七種獨立原畫時以通用效果呈現，並不宣稱已取得官方七組動畫。

## 驗證狀態

- 已在 Linux 執行：原有及新增影像核心測試、模擬時鐘回歸、最適化 C++17 編譯、ASan／UBSan、小桃實際 PNG 的 alpha 聯集裁切與取樣。
- 新增 Windows 測試：原創幾何 PNG 的透明／預乘色及裁切、局部 GIF 影格、disposal 2／3、延遲時間；由原有 CTest／Actions 呼叫。測試圖為本次自行建立的幾何圖，不含第三方角色。
- 本環境沒有 MSVC、Windows SDK 或 Windows 桌面，v1.1.1 EXE、GDI+ 實際解碼、檔案對話框、GIF 畫面與角色切換後的 GUI 尚未驗證。不能把 Linux 核心通過視為 Windows 解碼已通過。
- Windows 待測：透明 PNG／動畫 GIF 匯入、七槽／缺素材 fallback、改名、重啟離線載入、裁切與 DPI、拖曳／回彈、提醒與選單、切回十種原生角色；匯入或切換途中倒數／循環／鬧鐘不中斷；檔案刪除／格式錯誤／超限時可正常使用原生角色。

## 發布界線

更新器、簽章及 ZIP 白名單不變，匯入的資料檔不加入更新包。`tools/Package.ps1` 仍只打包原本五個明確允許檔案；自訂資料夾也加入 `.gitignore`。使用者若要預載第三方角色，須先取得相應授權再另外評估，這次不處理發布、金鑰、Tag 或 Release。
