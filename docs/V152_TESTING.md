# v1.5.2 實作及驗證

基準：GitHub main 與正式 v1.5.1 Tag 同為 `7e0e6831a509de686ee3d6fda71cce49dd5fc679`。本次使用全新乾淨 clone，先讀 AGENTS.md；未採用先前有變更的工作區。版本只在 CMake 單一來源改成 1.5.2，RC／manifest／Updater／關於沿用範本生成。未建立 Commit、Tag 或 Release。

## 八項需求

1. 透明度沿用大小的原生 ScaleWindow，依用途參數使用 20～100%，有雙向 Edit／Trackbar、100% 重設、33 ms 節流與確定／取消。寵物和名牌共用 Config.opacity；背景持續計時或更新存檔時，保存預覽前值。沒有拖曳寫檔迴圈。
2. 三組動作管理沿用內容雜湊檔名、原解碼器與限制。待機存在才可開啟六列管理；每列獨立匯入／替換、實際循環動畫預覽、狀態、來源檔名、移除。匯入先存隨機草稿目錄，完整驗證成功才修改草稿；確定前再次檢查雜湊及解碼，取消／關閉清理草稿，原設定不變。既存有效內容檔不覆寫。idle 替換亦保留其他動作；資料更新先準備新的 CustomPet，成功後替換目前快取。預覽只解碼目前選取的檔案。
3. 台詞直接顯示八個多行輸入框及一般對話開關，三語分頁的寬度／列數檢查保留 v1.5.1 修正。分頁切換、預覽及確定前完成原生 IME 組字；三語全分類維持草稿，全部驗證後一次套用，取消不變更台詞。分類、字數／句數／1 MiB JSON 上限與原語言回退不變。可縮放、最大化及捲動；內容使用獨立裁切 viewport、批次移動、SWP_NOCOPYBITS／NOREDRAW，再由捲動／大小事件統一重繪，沒有高頻重繪 timer。
4. 使用附件 DesktopPet.ico 原始位元組，包含九尺寸 RGBA PNG；既有資源 ID 1 同時嵌入兩 EXE。品牌載入集中於 platform.h，以 DPI 選擇共享 icon；主程式、系統匣、關於大圖、設定／更新／預覽及更新器進度窗統一設定。快捷方式引用原 EXE 路徑／資源索引，無額外舊 icon 路徑。export_assets 不再覆寫品牌。只新增 ICO，不複製附件大 PNG。舊檔原位替換，不需刪除其他檔案。
5. 三個模式各自保存標題、文字、時間、排程、snooze 偏好及狀態。舊 timer 的設定複製到三種模式，僅原活動模式保留執行／待確認／延後狀態；缺漏／損毀的多模式結構退回舊快照遷移。
6. TimerModes 包含三個獨立 Timer，使用原有可靠時間戳及睡眠校正，不以動畫幀累加。每個視窗取得自己的 Timer，啟動／暫停／繼續／停止／延後只改自身。佇列為模式 ID 的有界 FIFO，既有提醒維持順序，同次偵測到期依倒數、循環、鬧鐘順序；每模式最多一個待確認，重複週期合併而不中斷原週期。確認／延後操作佇列頭，接著呈現下一筆。啟動新任務或重設只重設該模式，停止也只移除該模式待處理項目。選單及提醒文字顯示模式，選單另顯示待確認數。模式的 started／due／remaining／snooze／pending 及 queue 均存入設定；更新重啟恢復全部，正常結束仍停止全部任務。
7. 可由舊原碼直接確認：isFullscreen 以任何前景窗所屬螢幕比外框，既未比對寵物 Monitor、也未排除 IsZoomed／標題框，造成副螢幕或最大化窗誤隱藏寵物，表面看似失去置頂；另外原 Z-order 只在尺寸／置頂操作時設定。新版同時比對寵物 Monitor、視窗外框及最大化／裝飾框，排除其他螢幕的全螢幕。前景 WinEvent 只送通知到 UI 執行緒，以 SWP_NOACTIVATE 維護使用者置頂設定；既有每秒檢查只在前景／螢幕／設定變更或 WS_EX_TOPMOST 不符時補正，不新增高頻輪詢。OS／特定軟體實際 Z-order 競態尚未實機重現，不能將原碼修正當作完成多螢幕實測。
8. 移除正式 main 渲染與檢視匯出的額外特效通道，以及 Sprite 的 Z／愛心／驚嘆號等額外符號方法。GIF／OCP 內像素、表情、動作及其原有特效未修改。名牌、台詞、提醒、縮放／拖曳／回彈與狀態觸發保留。Sprite 的完整角色／肢體示意繪圖與原回歸標準保留，正式寵物繪製不再額外合成其飾物。

## 設定及安全相容

schema 維持 1。`timerModes.tasks` 固定三項（ID 0 倒數、1 循環、2 鬧鐘），`queue` 最多三個模式 ID，`selected` 為目前設定模式；舊 `timer` 保留選定模式的相容快照。舊版只認得一個模式，降版前需備份設定，不會宣稱舊客戶端能保持新多模式資料。

`customProfiles[].fileLabels` 只保存顯示用來源檔名，實際路徑仍由既有 SHA-256 格式檢查決定。名稱 12 單位、自適應名牌、語言及台詞欄位／相容別名均保留。所有自訂素材留在 LocalAppData，沒有加入 Git 或發布白名單。

ECDSA P-256、主要／備援金鑰、SHA-256、信任狀態、DPAPI／DPJ3、交易日誌、復原／回滾、DLL 搜尋與 MSVC GS／CFG／DEP／ASLR 均未變更。updater/main.cpp 僅調整進度視窗品牌 icon／圖示及文字布局，交易流程不變；build.yml、Package.ps1、簽署及 provenance／EXE SHA 輸出不變。雙 ZIP 仍使用原封裝流程與五檔更新白名單。

## Linux 實際驗證

使用 GCC C++17、-O2 -Wall -Wextra -Werror -pedantic 編譯並執行既有六組及新增 v152_tests。最終數量／結果記錄在增量包 APPLY.md；計數包含逐像素及參數組合，不表示獨立功能數。

- 新增模擬時鐘：三模式設定／開始時間、同時到期、FIFO 上限、暫停／繼續／停止／延後隔離、週期相位、睡眠跨期／跨日／跨週及舊設定／佇列恢復。
- 新增三組動作草稿替換／移除／取消、待機門檻、狀態檔名／台詞存取隔離、三語全八分類保存／錯誤不部分提交及回退、隨機不連續重複、透明度邊界、負座標 Monitor 判定。
- v152_tests 的 ASan／UBSan（detect_leaks=0，不宣稱洩漏測試）及既有安全／敏感資料／Actions SHA／provenance 回歸。
- v152_asset_tests.py 驗證附件 ICO 雜湊、九尺寸／長寬比例／RGBA／所有 PNG chunk CRC，正式繪製無額外 overlay 通道與品牌載入位置。CMake 找到 Python 開發環境時亦註冊此項 CTest，不增加使用者 Runtime。
- 原素材驗證仍檢查全部 144 個預期雜湊；唯一授權變更是品牌 ICO 的預期雜湊，其餘 143 個保持原值。原斷言沒有刪除，另加專用品牌完整性測試。70 動作 GIF／840 播放位置與 OCP 一致、128 原陸生 GIF 及全部 22 外觀路由保留。
- 交付前實際套用 binary Patch 到基準檔案副本，逐檔比對位元組；新增檔／ICO／資源路徑一併納入，ZIP 檢查及敏感資料掃描。

## 容量與效能界限

ICO 原始來源從 9,662 增至 133,990 bytes，差 124,328 bytes；只內嵌一份於各 EXE，未複製多份大 PNG。所有寵物 OCP／GIF 及其解碼尺寸不變。多模式只有三個 Timer 與三項佇列，沿用原每秒時鐘；置頂只在前景／狀態事件補正。草稿及動畫預覽只在編輯視窗存活，預覽依原影格延遲刷新。以上是結構／來源資料界限，不是 Windows EXE 大小、程序記憶體或 CPU 實測結果。
