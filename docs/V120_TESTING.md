# v1.2.0 驗證紀錄（2026-11-26）

## 已執行

Linux x64／GCC，使用現有 v1.1.1 原始碼增量修改。無 MSVC、Windows SDK、CMake、PowerShell 或 Windows 桌面，未建立 Windows EXE、Tag 或 Release，未生成／替換金鑰。

- C++17 核心以 `-O2 -DNDEBUG -Wall -Wextra -Werror -pedantic` 編譯成功，`PASS: 534484 checks`。
- 相同核心測試以 AddressSanitizer／UndefinedBehaviorSanitizer 執行通過。此環境 LeakSanitizer 在 ptrace 下失敗，重跑時以 `ASAN_OPTIONS=detect_leaks=0` 停用漏洩檢查；沒有宣稱漏洩檢查通過。
- 新增翻譯 ID 唯一性、三語非空／UTF-8／格式參數完整性、系統語言回退、三語星期格式往返、v1.1.1 設定遷移及語言切換不影響計時。
- 五種動物＋通用文字，八種狀態各語言至少兩句；三語共 300 句。覆蓋全部十六外觀路由、虎皮／玄鳳識別、缺庫不得退回狗／其他語言、避免連續重複。
- 三組自訂台詞的 Unicode 多行解析、去重、容量驗證、各組切換／清除隔離、設定往返與更新恢復、通用／靜默備援、關閉閒聊仍保留提醒及自訂提醒原文。
- 既有模擬時鐘的倒數／循環／鬧鐘／延後、睡眠補正、設定、動畫、ZIP 拒絕路徑穿越、版本與信任政策回歸皆通過。總檢查數含大量逐像素斷言，不代表獨立使用情境數。
- 原 `sprite.h` 逐位元相同，沒有重生素材；可信根建置值與五檔白名單未變。ZIP 驗證器、信任政策與信任儲存除集中翻譯診斷文字外逐字相同，P-256 驗證函式未變。
- 原始碼 UTF-8 及替換版號後 manifest XML 解析通過；增量 Patch 套用與輸出逐檔一致性另外在交付時驗證。
